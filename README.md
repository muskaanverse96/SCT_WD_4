# TASKFLOW — Productivity Management App

TASKFLOW is a full-featured productivity and task management web application built using HTML, CSS and JavaScript.

## Features

- Add, edit and delete tasks
- Mark tasks as completed
- Due dates and times
- Task priorities
- Categories and tags
- Search and filtering
- Sorting
- Important/starred tasks
- Subtasks and progress tracking
- Drag-and-drop task ordering
- Dashboard statistics
- Daily progress
- Calendar view
- Productivity analytics
- Weekly completion chart
- Productivity streaks
- XP and level system
- Achievement system
- Pomodoro focus timer
- Focus mode
- Light, dark and violet themes
- Browser notifications
- LocalStorage persistence
- JSON data export
- JSON data import
- Responsive mobile design

## Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Browser Notifications API
